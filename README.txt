- DataCoSupplyChainDataset.csv (not included in zip to keep size small; place it in the folder)
- README with run instructions.

How to run the app locally:
1. Put DataCoSupplyChainDataset.csv in this folder.
2. python -m venv venv
3. source venv/bin/activate  # Windows: venv\Scripts\activate
4. pip install streamlit pandas plotly scikit-learn
5. streamlit run app.py
